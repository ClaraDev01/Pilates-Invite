# 🧘 Pilates Invite

A responsive website developed for a Pilates studio, featuring a modern interface and a contact system. The project focuses on providing an attractive online presence while making it easy for potential clients to get in touch.

- 🧘 Modern and elegant landing page
- 📱 Fully responsive design
- 📖 Studio presentation
- 📍 Contact information
- 📩 Contact form integration

## 💻 How to Run Locally

```bash
git clone https://github.com/ClaraDev01/Pilates-Invite.git

cd Pilates-Invite

cd backend
npm install
npm start
```

Then open:

```
frontend/index.html
```

in your browser.
