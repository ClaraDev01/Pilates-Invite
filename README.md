# 🧘 Pilates Invite

A mobile-first website developed for a Pilates studio, featuring a modern interface and a contact system. The project focuses on providing an attractive online presence while making it easy for potential clients to get in touch.

## 💻 How to Run Locally

```bash
git clone https://github.com/ClaraDev01/Pilates-Invite.git

cd Pilates-Invite/backend
npm install
npm start
```

Then open:

```text
frontend/index.html
```

in your browser.
